# 界面截图与风景照片

本目录为原生 Mac 相框和网页版的实际运行截图，使用独立的风景演示数据。未使用家庭照片、个人图库或私人服务配置；演示实例与日常相框分开运行。

截图中的照片来自仓库已有的 `themes/nature-calm/wallpapers/`，原始出处及授权完整保留在[风景主题的素材说明](../../themes/nature-calm/CREDITS.md)。
